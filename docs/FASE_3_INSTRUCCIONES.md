# Fase 3 — PostgreSQL en Supabase

## Cómo usar estos archivos

1. Copia la carpeta `database` dentro de `C:\Proyectos\comerciabi`.
2. En Supabase abre `SQL Editor` y crea una consulta nueva.
3. Ejecuta los archivos en este orden:
   1. `database/migrations/001_tipos_enumerados.sql`
   2. `database/migrations/002_tablas.sql`
   3. `database/migrations/003_funciones_triggers.sql`
   4. `database/migrations/004_indices.sql`
   5. `database/migrations/005_habilitar_rls.sql`
   6. `database/seeds/001_datos_demo.sql`
   7. `database/tests/001_verificaciones.sql`
4. No avances al archivo siguiente si aparece un error.
5. No guardes en Git la contraseña de PostgreSQL ni ninguna clave secreta.
